# ドラゴンボート レース分析ツール - 公開フォルダ

このフォルダを GitHub(SBM-Labo)に置いて GitHub Pages で公開すると、URLを知っている人がブラウザから直接GPSデータを閲覧・分析できます。
ツールが読むデータ(manifest.json / race_results.json / data/ 以下)はすべて GitHub から取得します。ローカルのCSV/XLSXを読み込む機能はありません。

公開URL: https://sbm-labo.github.io/db-analyzer-dragon-boat/
(index.html 冒頭の `GITHUB_BASE` で設定。リポジトリ名を変えた場合はここも変更)

## ファイル構成

```
db-analyzer-public/
├── index.html              ← 解析ツール本体
├── manifest.json           ← レース一覧データ (CSV経路、自動生成)
├── race_results.json       ← 公式タイム・着順データ (PDF解析、自動生成)
├── generate_manifest.py    ← manifest.json 生成 + xlsx→csv 変換
├── scripts/
│   └── parse_race_results.py  ← PDF → race_results.json 解析スクリプト
├── README.md
├── deploy_guide.md
└── data/                   ← GPS CSV データ
    ├── 2025-11-02/         (53レース)
    ├── 2025-11-16/         (19レース)
    └── 2026-07-19/         (61レース)
```

## 機能

1. **GPS速度プロファイル可視化**: 大会別レース一覧(GitHub上のデータ)から選んでスピード曲線を描画。複数レースを重ね描き比較。
2. **公式タイム表示**: race_results.jsonの公式タイム・着順を自動表示。
3. **URLパラメータ起動**: `?team=...&races=...` でチーム別カスタムURL。
4. **xlsx対応**: generate_manifest.py が xlsx→csv に自動変換して一覧に登録。

## データ更新ワークフロー

### 新しい大会データを追加するとき

```bash
# 1. CSV/XLSX を所定フォルダに置く
mkdir -p data/2026-XX-XX
cp /path/to/*.csv data/2026-XX-XX/      # CSV/XLSX どちらも可

# 2. manifest.json を更新 (xlsxは自動的にcsv変換)
python3 generate_manifest.py

# 3. レース結果PDFを解析して race_results.json を更新
python3 scripts/parse_race_results.py path/to/結果.pdf -o race_results.json

# 4. GitHub (SBM-Labo) に push → GitHub Pages に反映
```

### ファイル命名規約

`R<番号>_<クラス>_<レーン>_<チーム名>.csv|xlsx`

例:
- `R24_オープン決勝_02_魚橋水神龍会.csv`
- `R25_混合決勝_01_関西龍舟シンバ.xlsx`

この規約に従うと、ツール側で自動的に公式タイムとマッチングされます。

## 推定データ(GPSなし)について

ファイル名のチーム名に `(推定)` が付いているCSVは、GPS実測ではなく解析で再構成したデータです。

- `data/2026-11-01/R36_オープン決勝_01_磯風漕友会(推定).csv`
  - 2026/11/01 オープン決勝(R36)の磯風漕友会はGPSが未装着のため、次の方法で速度波形を再構成した。
    - 決勝映像(60fps)を固定カメラモデルで解析し、他艇(bp・水俣龍舟・ヨイショ)のGPSを較正点として平均速度を推定(〜40秒)
    - 40秒以降は予選③(R13)の本人GPS波形の形を使用
    - ストロークごとの細かい速度変動は、予選③の速度波形をストローク単位でコピー(ピッチは決勝映像から109〜111回/分で予選と同じことを確認)
    - 予選③の速度波形は、GPS速度(ゆっくりした変化)とTeam AMSの前後加速度100Hz(ストローク内の変化)を相補フィルタで合成したもの。GPS速度だけではストローク内の振れ幅が実際の約1/2〜1/3に平滑化されるため
    - 公式タイム 1:06.13 で 250 m になるよう合わせている
  - 平均速度の精度の目安は ±0.1 m/s 程度。個々のストロークの山・谷の時刻は実際の決勝とは対応しない。
  - X/Y・緯度経度は、bpのGPS軌跡をもとに1レーン分(約12 m)ずらした名目上の座標。

## 加速度センサーによるストローク解析 (2026/11/01)

2026/11/01 の GPS ファイル105件には、同じ端末 (SPI ProX2) の加速度データを使ったストローク解析データがある。

- `data/acc_index.json`: 加速度データがある GPS ファイルの一覧。ツールはここに載っているレースだけ追加データを読む
- `data/2026-11-01/stroke/<GPSファイルと同名>.json`
  - `v`: GPS速度 (0.6 Hz より遅い変化) と前後加速度 Y軸 100 Hz の積分 (速い変化) を相補フィルタで合成した速度 (20 Hz、`t0` はファイル先頭からの時刻 [s])。公式タイムで 250 m になるよう補正済み
  - `st`: 加速度で検出したストローク (キャッチ = 艇の加速度が負→正に変わる点) ごとの値。列名は `st_cols`
  - `shape`: 巡航区間 (25 秒〜ゴール10秒前) の平均ストローク波形 (速度/平均速度、前後加速度)
  - `sum`: レース指標 (巡航SR、DPS、速度変動幅、ドライブ比、ピーク加速度など)
  - `q`: 加速度と GPS の時刻合わせの結果 (ずれ [s]、相関、距離補正係数、加速度のカバー率)
- ツールでは、これらのレースに「加速度」の印が付き、速度グラフ・ストローク検出・SR・DPS が加速度ベースになる (グラフ上部の「加速度」で GPS のみに切替可)。「6b. ストロークの中身」パネルに平均ストローク波形と指標を表示
- 加速度は Team AMS の Accelerometer タブ「Excel Link」で書き出したもの。R35 レーン1 (漕遊人) はゴール約10秒前で加速度の記録が終わっている

## 公式映像 (YouTube) のレース別再生

- `race_videos.json`: 大会ごとの公式中継の YouTube 動画IDと、レース番号ごとの「GPSファイル先頭 (スタート) の映像内時刻 [s]」
  - 2026-11-01: 滋賀県ドラゴンボート協会「第14回スモールドラゴンボート日本選手権大会 中継」(4iU6fDkoBqk)。GPS のスタート時刻 − 約9:01:00 を起点に、レースごとに映像のスタート場面で艇が動き出す時刻を画像の差分から検出し、その約0.4秒前を号砲とした (±0.5 秒)。検出できなかった R1・R2・R4・R5・R27・R30〜R32 は前後のレースの値で補った
  - 2025-11-16: 滋賀県ドラゴンボート協会「第13回スモールドラゴンボート日本選手権大会　中継」(ZqfZty91Vec)。R17〜R26。発艇側の遠景カメラで艇が動き出す瞬間を目視で読み取り、その約0.4秒前を号砲とした (±0.5 秒。GPS のスタート時刻 − 約8:57:03 にほぼ一致)
  - 2025-11-02: 大会HP (https://www.jdba-dragonboat.com/tresult/2374/) のレース別動画 (jdbamovie)。決勝の R21 (スモールB決勝)・R22 (スモール決勝)・R23 (混合+女子決勝)・R24 (オープン決勝) のみ。レースごとに動画が別なので `races` の値を `{"v": 動画ID, "t": 号砲の映像内時刻}` で書く。号砲は漕ぎ出しの目視 (±1 秒)、R24 は動画がスタート約16秒後から始まるため、ゴール通過から逆算 (t が負)
- 公式映像のないレースだけを表示しているときは、映像の枠に「公式映像はありません」と表示する
- ツールでは、映像のあるレースを読み込むと「▶ 公式映像」パネルが出て、レースごとにスタート10秒前から再生できる。再生中は速度グラフ上に映像と同じ時刻の位置 (●) を表示
- 中継の音声は R10 以降に入っている (R1〜R9 は無音)。音声のあるレースは「「ゴー」で押す」ボタンで「アテンション・ゴー」の「ゴー」の瞬間をスタートに合わせられる (レースごとに端末に保存、±0.5 s 調整も可)。「調整値をコピー」で得た値を race_videos.json に書けば全員に反映される
- 動画は YouTube の埋め込みで再生しており、映像ファイルの切り出し・再配布はしていない

## ピッチ走法 → ストローク走法の切替

- ツールの「4. レース分析指標」の「ピッチ→ストローク切替」と、速度・SR グラフの ▼ と点線で表示
- 定義: スタート25秒以内の最高SR (3本平均) と巡航SR (25秒〜ゴール15秒前の中央値) の中間を、最高SR以降に初めて下回った時刻。最高SR − 巡航SR が 6 spm 未満なら「なし」
- 加速度データがあるレースは加速度で検出した1本ずつのSR、ないレースは速度波形から推定したSRを使う

## 上から見たレース展開

- 「▶ 上から見たレース展開」パネル: 表示中のレースを GPS の X, Y から上から見た図にしてアニメーション表示 (艇の先端 = スタートからの距離、横 = GPS の横位置)。パドルは検出したストロークの時刻に合わせて動く
- 公式映像の再生中は映像と同じ時刻を表示 (同期を外すと単独で再生・スライダーで移動、0.25〜2×)

## フィードバック (自動コメント)

- 比べる相手は、同じ大会・同じ艇種 (スモール/標準艇)・同じ種別 (オープン・混合・女子・シニアなど。8艇未満なら同じ大会・艇種) の全艇。大会ごとに風・水面の条件が違うため大会をまたいでは比べない
- 「上位25%」= その中の公式タイム上位4分の1の艇の区間タイム・指標の中央値。◎ = 大会内上位25%以内、△ = 下位25%、○ = その間
- 項目: 総合 (順位率・1着との差と区間ごとの差) / 最優先課題 (上位25%との差が最も大きい局面: スタート0–50 m・中盤50–200 m・ラスト200–250 m) / スタート (0–50 m タイム、原因としてスタートのピッチ・最高速度・到達本数) / 切替 / 巡航 (50–200 m の速度差を ピッチ と 1本の進み に分解) / ラスト (最速区間比、ピッチと1本の進みのどちらが落ちたか) / リズム
- 全艇の指標は `data/bench.json` (作り方は tools/README_bench.md)
